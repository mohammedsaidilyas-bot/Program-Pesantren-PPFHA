# APK Uji Program Pesantren PPFHA

Android WebView yang memuat website produksi https://program-pesantren-ppfha.vercel.app/ tanpa mengubah website, Apps Script, Google Sheets, maupun notifikasi wali santri.

Fitur: izin kamera untuk pemindai KTS/QR berbasis getUserMedia, DOM storage, JavaScript, tombol kembali Android, dan layout responsif mengikuti website.

Cara mengunduh: buka GitHub repository > Actions > Build APK Program Pesantren PPFHA > run sukses > Artifacts > Program-Pesantren-PPFHA-APK-Uji. ZIP berisi app-debug.apk. APK ini ditandatangani dengan debug key khusus pengujian; bukan versi Play Store. Membutuhkan internet.

Penting: jangan membagikan APK pengurus kepada wali santri. Autentikasi dan hak akses pada website tetap wajib diterapkan oleh sistem asal.
